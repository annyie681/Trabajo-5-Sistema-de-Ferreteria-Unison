# Trabajo-5-Sistema-de-Ferreteria-Unison
Trabajo 5 para CV - Sistema de Ferretería para la Universidad de Sonora

Creadores: Hernández Morales Anahí López Corella David Antonio Sandoval López Daniela

Descripción: Es un sistema de gestión diseñado para una ferretería. Cuenta con módulos para procesar ventas, controlar inventario incluyendo advertencias, administrar proveedores, manejar la lista de clientes y generar reportes y respaldos.

Información Adicional: Creado por medio de Canva, utilizando sus herramientas para agregar botones e interactividad entre los distintos escenarios del sistema. Diseñado para poder acceder por usuarios diferentes con distintos permisos.
